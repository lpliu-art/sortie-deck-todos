01 问题 · 核心矛盾

已经有 AI，总线仍是传话筒

缺的不是又一个聊天窗口。缺的是一条大家共同遵守的出击：真相碎在粘贴里，航线停在口头，门禁停在群 @。

一条典型接力
  1. 产品自己的 AI 写出需求文档
  2. 澄清会纪要经 IM 再转发一遍
  3. 研发 / 测试把同一份需求丢进各自的 AI
  4. 提测继续传话；截图当契约
真相 多份粘贴 航线 看不见 门禁 审不了
02 方案 · 控制面

用控制面换掉聊天接力

Sortie Deck 按任务集结角色 Agent，用 LangGraph 编排出击。四件套一起上，传话筒才退场。

控制面四件套
可确认航线规划官提案，真人确认或手改后才编译图、才出击。
产物契约阶段写命名文件。下游读文件，不读某个人的聊天记录。
HITL 门禁interrupt() 暂停。放行、打回、改写、停止、重路由可回放。
共享上下文同一 Brief、同一航线、同一组产物与决策，角色之间拉平。
Brief 规划官 真人确认 角色 Agent HITL 提测 / 交付
03 对照 · 传话筒 vs 控制面

六处差异，都回到同一件事

IM 可以通知。真相留在航线、命名产物和 HITL 上。

传话筒的三笔账
  1. 真相碎了需求、纪要、截图各有一份，对不上版本。
  2. 航线是口头的谁先做、哪里并行、何时提测，群里现说。
  3. 门禁审不了放行停在一句 @，事后无法回放。

中大型产研的成本就在这三笔：接力变长，迭代变慢，合规对不上记录。

维度传话筒Sortie Deck
总线IM 当总线，人当传话筒小队频道可见协作
AI每人各开窗口、粘贴接力任务级角色 Agent + 可插拔执行器
契约截图 / 聊天命名产物，下游读文件
航线口头约定提案后真人确认才出击
门禁群里 @ 一下interrupt() HITL，可恢复可审计
上下文锁在个人聊天里全员同一 Brief、航线、产物与 HITL
04 商业价值 · 定性，非客户实测

少传话，才有迭代控制权

面向中大型产品与工程团队。下面是设计对应的定性结果，未引用客户，未给出实测数字。

  • 01 · 少接力 传话筒把同一份需求誊进产品、工程、测试、发布四个窗口。
    控制面沿一条出击交接：四个角色读同一份 Brief 和命名产物。
  • 02 · 快闭环 并行波次停在群里等口径，迭代被 IM 排队。
    航线确认后按阶段推进，波次对齐的是文件，不是下一条消息。
  • 03 · 可回放 谁确认了航线、谁放行了门禁，散落在聊天记录里。
    确认、HITL 动作和产物路径留在控制面上，合规可以回放。
  • 04 · 数据自持 出击上下文若只活在外部聊天产品里，团队并不真正拥有它。
    Apache-2.0，可本地部署。知识与产物留在自有环境。
四笔账都对着传话筒
真相不再拆成四份粘贴。Brief 与命名产物是这一次出击的版本。
航线确认之后才跑。并行波次对齐文件，不等下一条群消息。
门禁HITL 留在控制面上，合规回放的是动作，不是聊天摘录。
数据开源、可本地部署。知识、记忆和产物留在自有环境。
05 上下文平权 · 沟通协作

同一份真相，协作发生在明处

传话筒制造特权粘贴：最后粘贴的人掌握上下文。控制面把出击上下文拉平，再把讨论和审批分开。

上下文平权
产品 · Brief任务说明只有一份，不靠转发。
工程 · 航线确认后的阶段与并行，全员可见。
测试 · 产物读命名文件，不对着截图猜版本。
发布 · HITL放行与打回在同一条可恢复轨迹上。

知识与记忆按工作区、任务、角色作用域注入执行中的 Agent。带阶段标签的记忆只到达对应阶段，并行分支不会串味。

结构化协作

小队频道让讨论、阶段消息和决策全员可见。它是协作层，真相仍在航线和产物上。

@product @eng @qa @deploy
/confirm /start /approve /reject /rewrite /stop

HITL 是一等门禁：interrupt() 暂停图。放行、打回、改写、停止、重路由都写回控制面。IM 只承担通知。

06 机制 · 拆掉传话筒的四个抓手

对象在控制面上，不在对话历史里

01

任务是一等公民

  • 出击、阶段、HITL、产物都是对象
  • Agent 是执行单元，不是唯一界面
  • 状态可停、可恢复，不靠翻聊天记录
02

先确认，再编译

  • 规划官按 Brief 提案，含并行
  • 真人确认或手改后才编译 LangGraph
  • 未确认不能出击
03

契约，不是粘贴

  • 阶段输出命名文件
  • 下游只读文件
  • 并行路径作用域，避免互相覆盖
04

门禁是图语义

  • interrupt() 暂停
  • 放行 / 打回 / 改写 / 停止 / 重路由
  • 权限阻断也可转成待人工处理
